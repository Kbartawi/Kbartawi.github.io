Problem

Producing a video can mean moving between separate tools for scripts, images, voice and editing. Revisions require the same creative direction and preferences to be repeated. Frame is being built to keep that context in one production workflow.

Users
People who want to make videos without learning editing or prompting
Buyer
Individuals making personal reels and small-business content — initial audience
Market
Initial personal use; broader audience under validation
Stage
Active prototype · Production validation

FEATURES

  1. 01

    Start with a spoken or typed idea and develop it through a saved conversation.

  2. 02

    Plan the hook, research, script and visual storytelling around the selected format.

  3. 03

    Coordinate scene generation, voiceover, sound, captions and editing through one production workflow.

  4. 04

    Review the film, request focused revisions and prepare the video and thumbnail for download.

Examples

  • Turn a spoken observation into a short explainer with a clear hook and payoff
  • Develop a cinematic short or product video without coordinating separate production tools
  • Ask for a targeted scene or script revision while preserving the rest of the film

How it works

  1. 01

    Describe and develop the idea

    A researched idea, timed script and scene-by-scene production plan

  2. 02

    Approve the script and production direction

    Generated footage with a narration, sound and caption plan

  3. 03

    Generate, edit, review and export

    An edited video export with a thumbnail and reviewable production history

The earlier photo/title/resume/export/gallery flow was verified through the UI; the latest controls and actual Photos/sharing still need visual and real-device checks. The web studio offers Kling and Seedance with 174 mocked tests. AI creative acceptance and TestFlight release remain pending.

Commercial readiness

Personal use first; acceptance, repeat use and production economics are unvalidated.

  • VerifiedProduct workflow

    The web pipeline completed one real personal-photo film, including voice, captions, gallery playback and an identical downloaded file. Operator fixes were required. The public studio still uses fixtures.

  • In progressVerification

    Provider-mocked tests pass. The first live result was rejected for creative and voice quality. Native SwiftUI source exists, but iPhone runtime acceptance is pending.

  • In progressHosting and data

    The hosted studio is a static sample. Real generation runs on the private Mac with local storage; the new native editor is designed to render on-device. There is no public authenticated generation backend.

  • Not checkedCustomer validation

    Personal use comes first. Real-user completion, repeat use and cost per accepted film are not yet validated.

  • In progressRelease gate

    Accept a film for both technical and creative quality, verify native photo/video/voice export on-device, then complete signing, TestFlight upload and required Apple review. No TestFlight build is released.

The public studio uses built-in sample data. Its displayed scores, prices and media are fixtures. The screenshots demonstrate the product interface; the coastal film stills are separate portfolio concepts.
